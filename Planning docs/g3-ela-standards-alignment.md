# G3 ELA standards alignment (lesson pages)

Every G3 ELA lesson page (`lesson-W-*.html`, weeks 1–32, no week 17 files) shows the Florida B.E.S.T. benchmarks below in its Standards Alignment bar, the sparkle **ⓘ Lesson details** pill, and the footer. All days in a week share the week's set.

**Source of each code:** what the week's lessons actually teach (WGRD reading skill, Writer's Workshop task, morphology, spelling, grammar, Poetry, fluency), checked in the lesson HTML on 2026-11-09. The `3rd_grade_ela_scope_sequence_v2_poetry.xlsx` Primary Standards column was the starting point. It was not copied as-is because its reading and writing rows are on the old book order (Gulliver/Joan of Arc weeks and Whipping Boy at W13–16). A code is listed only when a lesson activity teaches it.

## Code key

- `ELA.3.R.1.1` — character, setting & plot development
- `ELA.3.R.1.2` — theme
- `ELA.3.R.1.3` — characters' perspectives
- `ELA.3.R.1.4` — poem types (free verse, rhymed, haiku, limerick)
- `ELA.3.R.2.1` — text features & structures
- `ELA.3.R.2.2` — central idea & details
- `ELA.3.R.3.1` — figurative language (metaphor, personification, hyperbole)
- `ELA.3.R.3.2` — summarize
- `ELA.3.R.3.3` — compare how two authors present a topic/theme
- `ELA.3.C.1.2` — narrative writing
- `ELA.3.C.1.3` — opinion writing about a text
- `ELA.3.C.1.4` — expository writing
- `ELA.3.C.1.5` — plan, revise, edit
- `ELA.3.C.2.1` — oral presentation
- `ELA.3.C.3.1` — conventions (grammar, capitalization, punctuation, spelling)
- `ELA.3.F.1.3` — phonics & word analysis (syllable types, affixes, multisyllabic)
- `ELA.3.F.1.4` — fluency
- `ELA.3.V.1.2` — morphology (base words, affixes, roots)
- `ELA.3.V.1.3` — context & word relationships
- `ELA.K12.EE.1.1` — cite evidence
